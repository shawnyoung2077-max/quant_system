  ⚠️ 用哪个波动？floor 衡量的是「换手成本相对你承担的风险有多贵」。
     换手成本按【成交额】计，风险按【组合波动】担 ⇒ 应该用【组合】波动。

     （单个策略的波动会小得多 —— 例如 carry 只有 2%/年 —— 但 floor 是

2. 标定：floor_crypto / floor_eq = (cost_eq/σ_eq) / (cost_crypto/σ_crypto)
====================================================================================================
  股票侧参照（【假设】，逐项列出以便替换）：
     往返成本 = 10 bps，日波动 = 0.012（≈年化 19%/√252）
     → 成本/日波动 = 833.3

  ==> 加密地板 = 0.125 × (833.3 / 317.0) = **0.3286**

  方向检验（容易搞反，所以显式写出来）：
     加密成本绝对值【更高】（14 vs 10 bps），但日波动约为股票的 3.7 倍
     ⇒ 成本/波动 更【小】(317.0 < 833.3) ⇒ 换手相对更便宜
     ⇒ 地板应该【更高】= 对【低换手】策略更不宽容：0.3286 > 0.125
     这与「加密手续费贵所以更该罚换手」的直觉相反 ——
     后者混淆了【绝对成本】与【波动调整后的成本】。

4. 地板的【作用方向】：它只影响低换手策略
====================================================================================================
  分母 = max(floor, TO)：
     · TO > floor → 分母 = TO，地板【完全不起作用】
     · TO < floor → 分母 = floor > TO → Fitness 比 floor=0 时【更低】
  ⇒ 地板是给低换手策略设的【惩罚下限】，不是给高换手设的宽容。

  用 carry 实测指标（Sharpe=5.91, 年化=12.8%）扫描换手：

日换手        floor=0.125  floor=0.33   floor=0.50   地板起作用?        
----------------------------------------------------------------------------------------------------
0.030      16.92        6.44         4.23         是             
0.055      16.92        6.44         4.23         是             
0.125      16.92        6.44         4.23         是             
0.200      10.57        6.44         4.23         是             
0.330      6.41         6.41         4.23         是             
0.500      4.23         4.23         4.23         否             
1.000      2.11         2.11         2.11         否             
2.000      1.06         1.06         1.06         否             

  读法：
     · 换手 0.03（< 0.125）时三个地板的 Fitness 各不相同 ⇒ 地板起作用
     · 换手 1.00 / 2.00（> 所有地板）时三者完全相同 ⇒ 地板不起作用
     · carry 换手 0.055 属【低换手】，地板影响它：floor=0.125 → 16.9，
       floor=0.33 → 6.4（差 2.6 倍）

  ⚠️ 但 carry 的 Sharpe 高达 5.91，无论用哪个地板 grade 都是 EXCELLENT。
     地板在【边缘策略】上才有决定性 —— 见下一节。

5. 地板真正决定 grade 的地方：边缘策略
====================================================================================================
  取一个「边缘」策略：Sharpe=1.6, 年化=8%, 日换手=0.05

地板           Fitness      BRAIN grade    可提交(GOOD+)    
----------------------------------------------------------------------------------------------------
0.125        3.620        EXCELLENT      True          
0.200        2.263        EXCELLENT      True          
0.329        1.377        AVERAGE        False         
0.400        1.131        AVERAGE        False         
0.500        0.905        INFERIOR       False         

  ⇒ 同一个策略，地板从 0.125 提到 0.33：Fitness 从 3.620 降到 1.377，
    grade 从 EXCELLENT 变 AVERAGE。

  ★ 这才是标定地板的真正意义：
     对高 Sharpe 策略，地板怎么取都是 EXCELLENT，无所谓；
     对【低换手 + 中等 Sharpe】的边缘策略，地板直接决定它能不能提交。
     而加密策略的换手分布与股票不同，用错地板会让【整个筛选队列】发生偏移：
        · 地板取太小（0.125）→ 低换手策略被高估 → 提交一批不够格的 alpha
        · 地板取太大（1.0）→ 低换手策略被过度惩罚 → 漏掉真正的好 alpha

====================================================================================================
结论
====================================================================================================
  1. 地板只惩罚【低换手】策略；高换手策略与地板无关（最容易搞反的一点）。
  2. 按「成本/日均波动」推导，中性假设下加密地板 ≈ **0.33**（BRAIN 股票是 0.125）。
  3. 方向：加密波动是股票的 3.7 倍，而成本只高 1.4 倍
     ⇒ 换手相对更便宜 ⇒ 地板更高 ⇒ 对长持仓更不宽容。
     经济上合理：加密的单币波动与信用风险远高于股票，长持仓不值得奖励。
  4. ⚠️ 推导的输入含【假设】（股票成本/波动），敏感性区间 0.10~0.99，
     并非对全部输入都给出 >0.125。所以它给出的是【数量级与方向】，不是常数。
  5. 落地：`score_factor(..., turnover_floor=0.33)`；
     在 BRAIN 上调 alpha（股票口径）时仍用默认的 0.125。
