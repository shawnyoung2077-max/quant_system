# 交接文档 — Polymarket 体育市场错价建模

> 这份文档写给接手建模的人/模型。目标：**不重复我做过的工作，不重复我踩过的坑。**

---

## 一、任务是什么

**核心问题：Polymarket 的体育市场是否存在可利用的系统性错价？在哪些市场里？多大？**

具体要建的东西：

1. **一个错价预测模型**：给定 `(联赛, 价格, 成交额, 距结算天数, 市场类型)`，
   预测 `calib_err = outcome − price`（实际胜率 − 隐含概率）
2. **一个不确定性量化**：每个预测的置信区间（因为最终要拿它决定下不下注）
3. **一个可交易性判定**：预测的 edge 是否大于交易成本（费率 + 价差）

**判定成功的标准**：模型在**样本外**能识别出净 edge > 成本的机会，
且这个 edge 在扣掉手续费和买卖价差后仍为正。

## 三、已经确立的结论（不用重做）

### 3.1 总体上市场是有效的

在"所有时点都有价格"的受控样本（2,768 个市场）上，各时点偏差都很小且**符号随机**：

| 距结算 | 均价 | 实际胜率 | 偏差 |
|---|---|---|---|
| 30 天 | 0.211 | 0.209 | −0.0026 |
| 21 天 | 0.198 | 0.209 | +0.0106 |
| 14 天 | 0.215 | 0.209 | −0.0061 |
| 7 天 | 0.203 | 0.209 | +0.0057 |
| 3 天 | 0.203 | 0.209 | +0.0062 |
| 1 天 | 0.205 | 0.209 | +0.0041 |

**⇒ 全市场层面的定价偏差在 ±1% 以内，且不单调。没有"简单买冷门"这种机会。**

### 3.2 但在特定子集里存在显著错价

**① 冷门联赛的错价是热门联赛的 3 倍（联赛级，显著）**

按联赛成交额四分位（`league_vol_quartile`，1 = 最冷）：

| 距结算 | Spearman(联赛成交额, \|偏差\|) | p 值 |
|---|---|---|
| 7 天 | **−0.385** | 0.0069 |
| 3 天 | **−0.472** | 0.0004 |

3 天时点上，最冷档 vs 最热档：
- `|偏差|`：0.0819 vs 0.0248（**3.3 倍**），Mann-Whitney p = 0.0010
- `reliability`：0.0178 vs 0.0058（**3.1 倍**），Mann-Whitney p = 0.0082

**两个独立指标、两个检验方法都显著。这是目前最强的证据。**

**② 但容量是反的**：最冷联赛平均成交额 $12.9M，最热 $1.12B —— **差 87 倍**。
⇒ 百分比 edge 大 3 倍，但容量小 87 倍。**对小资金反而是对的选择。**

**③ 市场级成交额给出的方向相反（未解决，见第五节）**

### 3.3 交易成本（已实测，不是假设）

| 项 | 值 | 来源 |
|---|---|---|
| 官方费率公式 | `fee = C × feeRate × p × (1 − p)` | Polymarket 官方文档（已核实） |
| 体育类 taker feeRate | **0.05** | 同上 |
| Maker 费用 | **0**，且有 15% 返利 | 同上 |
| 地缘政治市场 | feeRate = **0**（实测 `feesEnabled=false`） | API 实测 |
| 最小 tick | 政治 0.001，体育 0.01 | API 实测 |
| 0.10-0.15 档实测价差 | 中位 **0.0100** | 实时盘口 n=18 |
| 订单簿前 10 档深度 | 中位 **$1,899** | CLOB book 实测 12 个市场 |

**⇒ 成本量级：费率约 0.005/股 + 跨价差约 0.005/股 ≈ 0.01/股。
而待检验的 edge 只有 0.02~0.03/股。成本吃掉 30%~50%。**

## 四、已知的六个坑（**这些我都踩过，请直接跳过**）

### 坑 1：跨时点比较的样本构成偏差 ★最坑

比较"30 天前的偏差 vs 7 天前的偏差"时，**不同时点覆盖的市场集合完全不同**。
30 天前只有 15% 的市场有价格。**直接比 = 拿苹果比橘子。**

我初版因此得出"中档偏差 +5%~+9%"的错误结论。

**正确做法**：只在同一批市场内比较（要求该市场在所有时点都有价格）。

### 坑 2：受控样本本身会引入新的选择偏差 ★同样坑

用了坑 1 的修正后，我拿到 2,768 个"全时点都有价格"的市场 —— 但**它被世界杯主导（1,582 个，占 57%）**。

原因：**"所有时点都有价格"这个条件本身筛选出了高流动性事件。**

后果：这个样本给出 `0.10-0.15 档 edge = +0.0161`（买 NO），
而**单时点全样本（16,527 个市场）给出 `−0.0270`（买 YES）—— 符号完全相反。**

**⇒ 修一个偏差会引入另一个。任何子集筛选都要问：这个条件本身在选什么？**

### 坑 3：de-vig 方法的选择能造出比 edge 还大的"信号"

从博彩赔率去掉抽水有三种主流方法，**分歧随抽水和价格极端程度急剧增大**：

| 情形 | 抽水 | 比例法 | 幂法 | Shin | **最大分歧** |
|---|---|---|---|---|---|
| 势均力敌 | 0.6% | 0.3426 | 0.3427 | 0.3427 | 0.0001 |
| 冷门档 8.89 | 4.4% | 0.1078 | 0.0992 | 0.1005 | 0.0086 |
| 绝大热门 1.10 | **8.7%** | 0.8364 | 0.8914 | 0.8688 | **0.055** |

**最大分歧 0.055 > 我们追的 edge（0.02~0.03）。**

**⇒ 任何基于参照价的信号，必须要求三种方法方向一致，否则你测到的是方法选择不是错价。**

### 坑 4：市场类型语义不可混用

Pinnacle 的 h2h（1X2）公允概率**只适用于胜负类市场**。
实测踩到：`Grazer AK 1902 0 - 0 FC Salzburg` 这类**正确比分**市场
队名能匹配上，但它的价格是"这个确切比分"的概率 —— 与 1X2 完全不是一个东西。

**⇒ 建模时务必用 `is_moneyline_like` 过滤，或至少按 `sports_market_type` 分层。**

### 坑 5：实体名匹配——宁可漏，绝不能错

**假匹配比漏匹配危险得多**：漏掉只是少个机会；假匹配会拿**别的比赛**的公允价
去算 edge，产出完全错误的数据，而且**不会报错**。

实测踩到的反例：
- `K League 1` vs `K League 2`（不同级别，用"有交集"会误匹配）
- `Austria Bundesliga` vs `Basketball Bundesliga`（足球 vs 篮球）
- `Draw (Incheon United vs. Pohang Steelers)` → 匹配到 `Gangwon vs Bucheon`（完全不同的比赛）

**规则**：短名的 token 必须是长名的子集 + 不能剥掉区分类别的数字 + 保留通用词黑名单。

### 坑 6：pandas 会把空字符串读成 NaN

`sports_market_type` 的空值在 CSV 里是**空串**，pandas 默认读成 `NaN`。
于是 `df["sports_market_type"].isin(["moneyline", ""])` 会**静默漏掉 14,920 行**。

## 五、未决问题（**这就是建模任务**）

### Q1 ★ 最重要的矛盾：市场级和联赛级成交额给出相反方向

| 分组方式 | 关系 | 显著性 |
|---|---|---|
| **联赛级**成交额 vs \|偏差\| | **负相关**（越冷门偏差越大） | p = 0.0004 ✅ |
| **市场级**成交额 vs 有符号偏差 | **正相关**（成交额越大偏差越大） | Q4 档 t = 7.82 ✅ |

市场级明细：

| `mkt_vol_quartile` | n | 偏差 | t |
|---|---|---|---|
| 1（最小） | 18,563 | +0.0044 | 1.22 |
| 2 | 18,561 | +0.0041 | 1.15 |
| 3 | 18,561 | +0.0200 | **5.60** |
| 4（最大） | 18,557 | +0.0280 | **7.82** |

**两个都显著，方向相反。必须先解决这个矛盾再谈建模。**

可能的解释（需检验）：
- 联赛级是**绝对值**比较，市场级是**有符号**比较 —— 可能只是聚合方式差异
- 世界杯等超大联赛的个别偏差主导了市场级 Q4
- 成交额高的市场往往价格更极端（更接近 0 或 1），而极端价格的偏差结构不同
- **提示**：请按 `mkt_vol_quartile × price_band` 交叉后再看，并做联赛固定效应

### Q2 错价的驱动因素是什么？可预测吗？

候选特征（数据里都有）：
`league_name` / `league_vol_quartile` / `mkt_vol_quartile` / `price` /
`price_band` / `lead_days` / `sports_market_type` / `n_points` / `neg_risk`

**关键**：错价是否**可预测**（有稳定的条件结构），还是只是噪声？
- 若能预测 → 可以下注，且能算置信区间
- 若不能 → 干净排除，省下所有后续投入

### Q3 时点结构

`lead_days` 从 30 到 1，错价是否随时间收敛？**理论上越接近结算越有效。**
若某些时点存在系统性错价，那才是可交易的（因为你有时间建仓）。

⚠️ 注意坑 1：跨 `lead_days` 比较必须用受控样本；但注意坑 2，受控样本有它自己的偏差。

### Q4 在扣除成本后还剩多少？

**必须把成本模型建进去**（见第三节 3.3）：
```
净 edge = 毛 edge − 费率(0.05·p·(1−p)) − 跨价差成本(约半个价差)
```
报告 edge 时请**同时给毛和净**，否则无法判断可交易性。

### Q5 容量约束下的期望收益

实测单市场盘口深度约 $1,900。所以：
```
可投入资金 ≈ 单市场深度 × 同时持仓数
```
建模时应输出"**在容量约束下的年化收益率**"，而不是无约束的均值 edge。

## 六、建模时的三条纪律

1. **样本外验证**：按**时间**切分（不是随机切分），因为市场结构在变
2. **多重比较校正**：我做过一次 15 个组合的搜索，出现 t≈2.8 的假显著并不意外。
   逐联赛/逐分档扫描请用 Benjamini-Hochberg
3. **报标准误，不只报点估计**：本项目历史上多次因"只看点估计"而误判

## 七、这个问题的战略背景（帮助你判断值不值得做）

- 用户是小资金（3-4 万人民币），所以**容量约束不构成限制**，百分比 edge 才是关键
- 对手是 Polymarket 上的休闲玩家（不一定是懂球的），而参照价来自 Pinnacle（机构）
- **但要注意**：如果差距是免费的钱，它早就消失了。它还在，说明要么不是免费的
  （结算规则差异、无法做空参照市场、资金进出摩擦），要么太小（职业机构看不上）。
  **这两者都削减收益 —— 建模时要正面回答"为什么这个 edge 还在"。**
