# quant_system

**数据无关的量化研究框架** —— 覆盖数据采集 → 因子挖掘 → 回测 → 组合构建 → 实盘执行 → 多市场适配。

> **同一套研究流程，适配三个结构完全不同的市场：**
> A股因子选股 · 加密资金费套利 · 预测市场有效性检验

自写代码 **约 5,300 行**（46 个核心模块，不含第三方 SDK）。

---

## 为什么是"数据无关"

核心引擎不关心数据来源，只要求一张 `日期 × 资产` 的价格面板。
接入新市场时，只需替换数据模块，回测/因子/指标层完全复用。

**这个设计在本项目里被验证了三次** —— 我把它分别接到了 A股、加密、Polymarket
三个数据结构和交易机制完全不同的市场上，上层代码没有改动。

## 一个负面结果（值得单独说）

在 Polymarket 上我检验了「预测市场是否存在系统性定价偏差」：

```
样本:   894,913 个已结算市场 / $211 亿累计成交
方法:   分档校准 —— 对比「隐含概率」与「实际结算频率」
```

**初版分析显示中档价格有 +5% ~ +9% 的偏差。** 但进一步检查发现问题：

> 不同观察时点的市场集合完全不同（30 天前只有 15% 的市场有价格），
> **初版的"偏差"是样本构成差异造成的假象。**

**修正后（只保留全部时点都有价格的同一批市场）：偏差在 ±1% 以内，符号随机跳动。**

唯一残留的信号是「价格 0.10-0.15 的合约被高估约 2~3%」——
**但 2~3% 不足以覆盖平台费率（rate 0.05）与买卖价差。**

**结论：不做。**

详见 [`polymarket/README.md`](polymarket/README.md)。

## 第二个负面结果：中性化把 alpha 拿掉了

给 Delta 中性 carry 装上 BRAIN 的后处理链（**中性化 → 截断 → 归一化**），
45 个变体全部做配对 t 检验：

```
显著改善 = 9   显著恶化 = 22   无差异 = 4   噪声 = 10
最好的"改善" = +0.54%/年（统计显著，经济微小，不改变结论）
真多空中性化(组内 demean) = 年化 -7.4% ~ -8.3%，t = -13 ~ -19.7  ← 把策略打崩
```

**三个反直觉的发现**（都有回归测试锁定，防止后人当 bug「修掉」）：

1. **等权组合上「截断 → 归一化」是恒等变换**，与 cap 取值无关。
   n 名每名 1/n：`cap ≥ 1/n` 不触发；`cap < 1/n` 全体压到 cap、归一化后**又变回 1/n**。
   ⇒ 截断只在权重本来就不等时才有意义。
2. **`cap < 1/n` 时「Σ|w|=1 且 |w|≤cap」不可行**（cap=0.05 时 94.7% 的交易日不可行）。
   必须按 cap 缩总暴露、剩余留现金。
3. **BTC-beta 中性化对 carry 是严格恒等变换**（差异 2.78e-17）——
   carry 每名都是「现货多+永续空」，价格 Beta 天然为 0，**没有 beta 可中性化**。

**经济解释**：carry 的收益是**多头风险溢价**（正资金费 = 多头拥挤 = 你在收租）。
做成 dollar-neutral 等于同时做多高费率、做空低费率，而**空头腿在倒付资金费** ——
整块溢价被抹掉，只剩噪声。**中性化不是免费的，它拿掉的正是 alpha 本身。**

### 副产品：爆仓+冷却期每年吃掉 3.35 个百分点

对齐两个 P&L 引擎时发现，2× 杠杆下 Delta 中性腿**仍会被强平**，
强平后 5 天冷却期权重清零 = 白丢 5 天资金费收入。
⇒ **「Delta 中性」不等于「安全」，杠杆仍会制造强平事件。**

## 第三个结果：尾部风险里，致命的不是价格，是信用

把三类尾部放进同一个赔率框架后，**排序与直觉相反**：

```
① 最致命  S3 交易所信用事件  → 两条腿同所，出事时同时归零；2× 本金损失
                               = 一次事件抹掉 15.6 年收益，且无法回本
                               而正常期年化只有 12.8% ⇒ 赔率不可接受
② 次致命  S2 基差暴走        → p99.9=0.0095, max=0.1665（日均资金费的 684 倍）
                               但分散化确实保护了组合：最坏的 ΔB 多在未持有的币上
③ 最不致命 S1 资金费符号翻转 → **选币机制天然防御了它**：只持费率最高的币
                               历史重放 85 段负费率区间，最大亏损仅 0.41%
```

**还被证伪了一个假设**：原以为「提币暂停 → 现货腿冻结 → 裸多 → 暴跌巨亏」。
实测**方向相反** —— 现货腿冻结 + 永续空头 ⇒ 净暴露 = **−w（空头）** ⇒ 暴跌反而赚钱。
**⇒ 提币暂停是【信用风险】，不是价格风险 —— 而信用风险不能用仓位管理解决，
只能用分散到多家交易所解决。对策完全不同。**

正常期波动 2.0% 是**样本选择**的产物：全样本 2559 天里，「连续负费率 ≥3 天」
只出现 85 段（最长 23 天），尾部事件频率太低，对样本方差的贡献可忽略。

📄 **完整报告：[`docs/TAIL_RISK.md`](docs/TAIL_RISK.md)**

## BRAIN Fitness 接入 + 加密换手率地板标定

BRAIN 的 Fitness 公式已用 **24 个 ACTIVE alpha 反推确认**（RMSE 0.0033）：

```
Fitness = Sharpe × sqrt( |年化收益| / max(0.125, 日换手) )
```

本次新增 BRAIN 官方 `grade` 字段（**只看 Fitness**，与 Sharpe 无关）与提交门槛判定；
并指出 **`0.125` 是股票市场的经验值，不该无脑套到加密上**。

**标定**（按「成本/波动」推导，`floor ∝ σ/cost`）：

| | 股票（BRAIN 假设） | 加密（本项目实测） |
|---|---|---|
| 往返成本 | 10 bps | **14 bps**（现货8+永续6） |
| 日波动 | 1.2% | **4.42%**（30币等权，实测） |

⇒ 加密地板 **≈ 0.33**（0.125 × 2.63）

**三个关键认知**（都有测试锁定）：

1. **地板只惩罚【低换手】策略**：分母是 `max(floor, TO)`，
   `TO > floor` 时地板**完全不起作用**。高换手与地板无关。
2. **「加密手续费贵所以更该罚换手」是错的** —— 方向相反：
   因为波动更高（3.7×）而成本只高 1.4×，加密是**低换手**受到更多惩罚。
3. **地板在边缘策略上直接决定能否提交**：一个 Sharpe 1.6 / 年化 8% / 换手 0.05 的
   策略，地板 0.125 → EXCELLENT（可提交）；地板 0.33 → **AVERAGE（不可提交）**。
   ⇒ 用错地板会让**整个筛选队列偏移**，这是"只提交 GOOD+"这个目标的直接风险。

⚠️ **诚实交代**：推导的股票侧参数（10bps / 1.2%）是**假设**，3×3 敏感性给出
0.10~0.99 区间，其中 **1/9 个组合低于 0.125** ⇒ 方向**不是**无条件稳健。
所以它是**数量级与方向**，不是常数。

📄 **完整报告：[`docs/BRAIN_FITNESS.md`](docs/BRAIN_FITNESS.md)**

## 一次「Sharpe 25.00」的证伪（本项目最有价值的一份文档）

Delta 中性资金费套利回测跑出 **Sharpe 25.00 / 年化 41%**。我不信它，于是：

```
① 四组可靠性检验     尾部拆解 ✅ / 参数稳定性 ✅ / Deflated Sharpe ⚠️ / 分年度 ❌
② 发现逻辑不可能现象  「筛选门槛越严，表现越差」25.00 → 12.82 → 12.06 → 10.32 → 6.34
③ 逐项排除           费用 ✅ / 资金费前视 ✅（仅 7%）/ 爆仓后未对冲暴露 ✅
④ 定位到公式错误      基差 P&L 用「今日权重 × 自入场以来累计基差变化」，且把累计值当逐日增量求和
⑤ 最小复现（手算）    正确答案 0.010000，legacy 给出 0.017778（放大 1.78×）→ 锁死谁对谁错
⑥ 修正 + 交叉验证     独立等权路径算得 +0.0168，修正后回测给出 +0.0137（同号同阶）
⑦ 预测兑现（最强证据）「越筛越差」的反常消失；且紧筛损失中基差项(−0.4676)是资金费项(−0.2314)的 2 倍
⑧ 闭环自洽           修正后年化 8.9% = 独立测得的资金费机制上限 8.9%（修正前 16.5%，超出 1.9 倍）
```

**Sharpe 25.00 → 4.95。** 样本外 Sharpe 2.70 才是更接近现实的估计。

关键是方法而非结论：**不要让"我改了代码之后数字变好了"成为证据。**
证据必须来自独立计算路径、事先做出的预测，以及与收益机制的自洽。

📄 **完整取证链：[`docs/DEBUG_carry_basis.md`](docs/DEBUG_carry_basis.md)**
（含可重跑验证脚本 `docs/verify/`，文档里每个数字都能追溯到一行脚本输出）
