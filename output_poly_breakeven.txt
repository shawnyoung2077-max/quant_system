====================================================================================================

  持有期 7 天 => n = 365/7 = **52.1 次/年**
  美债 r_f = 4.0%（与资金量无关的门槛）

  情形                                         k       k*n     k*n-r_f 能否保本
  ----------------------------------------------------------------------------------------------
  edge点估计 + spread=0.000                1.145%     59.7%      55.69% 可保本
  edge点估计 + spread=0.001                1.031%     53.8%      49.76% 可保本
  edge点估计 + spread=0.005                0.576%     30.0%      26.04% 可保本
  edge点估计 + spread=0.010                0.007%      0.4%      -3.61% **任何资金都不行**
  edge 95%下界 + spread=0.005            -4.016%   -209.4%    -213.40% **任何资金都不行**
  3天前edge + spread=0.005                2.416%    126.0%     121.98% 可保本

  * 两类截然不同的情形：
    - 全部【点估计】情形：k*n = 0%~126% >> r_f=4%
      => 只要 edge 为真，年化净收益远超美债 => **美债不是障碍**。
    - 【统计下界】情形：k = -4.016% < 0 => k*n - r_f < 0
      => **任何资金量都不盈利** —— 且亏损随资金等比放大。

  => 答案完全取决于「edge 是否真实」，而与资金量无关。

5. 更硬的约束：容量（钱投得出去吗？）
====================================================================================================

  实测：该档约 56 个标的/年，累计成交额中位 $186,529
  单仓上限（吃累计成交额 5%）= $9,326
  平均同时持仓 = 1.1 个
  => **可投入资金上限 = $10,016**

  ! 三处保守（真实容量只会更小）：
     1. 累计成交额是市场生命周期总量，不是建仓时的盘口深度
     2. 假设能吃掉 5%，实际滑点更大
     3. 只算了单一价格档

  * 一个反直觉但重要的发现（详见 output_poly_edge_capacity.txt）：
     edge 随成交额【递减】，$1M 以上甚至是负的：
       $10K-100K : +0.070 / +0.086 / +0.090  (t=2.0 / 2.5 / 2.8)
       $100K-1M  : +0.021 / +0.031 / +0.019  (t=0.8 / 1.4 / 0.8)
       $1M+      : -0.076 / -0.016 / -0.006  (t=-1.0 / -0.3 / -0.1)
     => 信号集中在【中低成交额】市场 —— 与「错价在低流动性处更大」一致，
        但也意味着**能承载的资金天然很小**。
     ! 而 $10K-100K 档的 t=2.5~2.8 是【分组搜出来的】：
       分组看了 5 档 x 3 时点 = 15 个组合，出现 t=2.8 并不意外，
       **不能当作独立证据**。

6. 结论
====================================================================================================

  用户问「要多少启动资金」。但这个策略的瓶颈不在资金，而在下面这条链：
  任何一环断开，投多少都是亏。

    edge 真实？      --X (t=0.78, CI 含 0) --> 不做
         | 假设为真
         v
    扣成本后为正？    --? (乐观 +1pp，悲观 约0) --> 边缘
         | 假设为真
         v
    k*n > r_f？      --Y (点估计 ~125% >> 4%) --> 美债不是障碍
         | 是
         v
    容量 >= C_min？   --? (容量 ~$10,016) --> 可行但规模极小

  => **如果 edge 为真**（3天前建仓、AI $50/月、spread 0.005 口径）：
       最小启动资金 = **$492**
       可投入上限   = **$10,016**  => 刚好可行，但规模极小
       注：该资金需求随 AI 月费【线性】放大 ——
           AI $100/月 => $984 ；AI $300/月 => $2,951

  => **如果 edge 是噪声**（现有数据无法排除）：
       k*n - r_f < 0 => **不存在能盈利的启动资金**。
       此时加大资金完全无用 —— 亏损随资金等比放大。

  * 直接回答：
     - 你现在需要投的不是钱，而是【更多数据】。
       该档 n=220；要让 2% 的 edge 达到 t>2，需要 n = **865**（当前 25%）。
     - 补足样本前，$0 是唯一理性的投入。
     - 补足后若 edge 确认，所需启动资金是 **$500~$2,300 量级**
       （取决于 3天前还是7天前建仓、以及真实价差；AI $50/月口径），
       但容量上限也只有 $10,016 上下 —— 这是个零花钱规模的策略，
       **不是能靠它生活的策略**。

  ! 方法论提醒：本次【费率公式】与【建仓时刻价差】都无法用本地数据复核
     （市场元数据的 bid/ask 是结算后快照，已失去意义；官方 docs 不可达）。
     所以成本是【参数化】的，不是实测的 —— 请看第 2 节的扫描而非单一数字。
